## ✨ Features
- ⏱️ 60-second typing challenge  
- 🔄 Random typing passages  
- ⏰ Real-time countdown timer  
- ⚡ Live **WPM**, **accuracy**, and **error highlighting**  
- 🟢 Correct (green) / 🔴 Incorrect (red) / 🔵 Current character (blue)  
- 💾 Best WPM saved using **Local Storage** (persists after refresh)

## 🧮 Calculations
- **WPM** = (Correct Characters ÷ 5) ÷ Minutes  
- **Accuracy** = (Correct Characters ÷ Total Typed Characters) × 100

---

## 🔒 Privacy
- No backend / no account  
- Typing data is processed locally in the browser  
- Only your **best WPM** is stored locally on your device
